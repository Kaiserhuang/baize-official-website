◈ 开源情报

洞鉴 · OSINT

Dongjian · Open Source Intelligence Platform

全球开源情报与侦察一体化平台。聚合航班追踪、CCTV 网络、地震监测、冲突区地图、新闻直播等 16+ 数据图层于单一 GPU 加速界面，配备 RECON 侦察工具包、AI 情报分析、加密货币追踪与 OFAC 制裁查询，提供军用级态势感知能力。

  • ✓ 全球实时情报仪表盘 — 16 个 GPU 加速数据图层
  • ✓ RECON 侦察工具包 — 端口扫描 / DNS / WHOIS / CVE
  • ✓ 直播广播网络 — 25+ 全球 24/7 新闻直播流
  • ✓ AI 情报分析 — Gemini + Ollama 本地 LLM
  • ✓ 加密货币追踪 & OFAC SDN 制裁交叉比对

◈ 情报分析

哥谭模拟

Gotham Simulatio · Intelligence Analysis Simulation

模仿 Palantir Gotham 的情报分析模拟系统。支持力导向知识图谱可视化、实体浏览器、事件时间线、全局搜索与地理地图模块。内置反洗钱与美伊冲突两大数据场景，适用于情报分析训练、威胁建模与态势推演。

  • ✓ 力导向知识图谱 — 交互式拖拽/缩放/展开
  • ✓ 实体浏览器 — 按类型过滤与全文搜索
  • ✓ 事件时间线 — 全时段回溯分析
  • ✓ 内置场景 — 反洗钱链条 / 美伊军事冲突
