# 笃行白泽（北京）科技有限公司 — 官方网站

笃行白泽聚焦开源情报分析（OSINT）与威胁仿真技术，为企业级用户提供态势感知与决策推演能力。

## 产品

### ⬡ 白泽洞鉴 — 全球开源情报与侦察一体化平台

基于 Next.js 16 + MapLibre GL 构建的实时全球情报仪表盘，聚合航班追踪、CCTV 网络、地震监测、冲突区地图、新闻直播等 16+ 数据图层，配备 RECON 侦察工具包、AI 情报分析（Gemini/Ollama）、加密货币追踪与 OFAC 制裁查询。

- 仓库：[Kaiserhuang/baize-dongjian](https://github.com/Kaiserhuang/baize-dongjian)

### ◉ 哥谭模拟 — 情报分析模拟系统

模仿 Palantir Gotham 的情报分析模拟系统，支持力导向知识图谱可视化、实体浏览器、事件时间线与全局搜索。内置反洗钱与美伊冲突两大数据场景。

- 仓库：[Kaiserhuang/gotham-simulatio](https://github.com/Kaiserhuang/gotham-simulatio)

## 技术栈

- 纯静态 HTML + CSS + JavaScript
- 暗色科技风 UI，内联 SVG 动画 Logo
- 粒子 Canvas 背景、打字机效果、3D 倾斜交互

直接用浏览器打开 `index.html` 即可。
